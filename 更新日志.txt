v2.0.0 —— 2026-08-14
【重大改进】
1. 独立运行：内置了独立 Node.js（runtime\node\node.exe，Node v22.22.2），
   客户端不再依赖 WorkBuddy。即使卸载 WorkBuddy 也能正常启动。
2. 真·应用窗口：改用 Microsoft Edge WebView2 把网页「内嵌」进程序窗口，
   不再弹出 Edge 浏览器，打开后看起来就是一个独立的桌面软件
   （无地址栏、无标签页、窗口标题/边框都是自己的）。
【技术细节】
- 新增运行时依赖（放在客户端根目录）：
    Microsoft.Web.WebView2.Core.dll
    Microsoft.Web.WebView2.WinForms.dll
    WebView2Loader.dll
  （来自 WebView2 SDK 1.0.4129.50，可从 nuget.org 下载升级）
- Node 探测顺序：内置 runtime\node\node.exe → WorkBuddy 的 Node → 系统 PATH。
- 网页仍由本地后台服务提供（node bin.js web @ http://127.0.0.1:3080）。
- 皮肤数据仍在 C:\Users\ASUS\.dsh\cordis.patch.yml（本版本未改动，保持深海女仆工坊）。

v1.0.0 —— 2026-08-14（首版）
- 桌面客户端雏形：WinForms 加载页 + 启动后台 + 自动打开 Edge 独立窗口(--app)。
- 依赖 WorkBuddy 自带 Node.js（v2.0 已解决此依赖问题）。
- 支持 config.txt 配置、--check 自检、源码 + build.bat 一键编译。

【踩坑】曾给客户端加「每次打开自动重启后台」，导致每次打开都杀掉当前会话/断网页（死循环），已撤销恢复为「复用后台」。新插件/皮肤需手动重启后台才生效；待加一个安全的「重启」按钮。
